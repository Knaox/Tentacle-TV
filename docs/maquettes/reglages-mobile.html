Ce qui est codé (branche claude/design-887719, commit « Pour vous · Affiner — une pastille en verre fixée sous l'en-tête ») : RecoSectionBar remplace RecoSectionSwitch, posée par ForYouScreen par-dessus les deux sections ; chacune réserve sa place en tête (RECO_SECTION_BAR_SPACE), démarrage à froid compris. Le verre n'est pas masqué : il est là parce que la page défile dessous (règle GPU n° 1 respectée). Décisions prises cette nuit

  • Le libellé reste « Affiner » (pas « Affinité ») : « Affinité », c'est la recherche à plusieurs de Watch Together (« Trouver quoi regarder ») ; deux mots proches pour deux fonctions auraient semé le doute.
  • Piste A retenue pour « Pour vous · Affiner » ; B écartée pour le conflit de gestes avec la pile, C parce qu'elle cache « Affiner ».
  • Structure des réglages : celle de la session reglages, sans écart (« Changer de serveur », Invitations, Sessions et « Vider le cache » rangés dans Compte › Serveur ; langue de l'interface côté Compte).
  • Changer de profil (consigne de Damien, 20/10) : la puce du profil actif dans l'en-tête de tous les onglets, un toucher → la feuille « Changer de profil », PIN dans la feuille ; aussi un bouton dans l'onglet Profil. Sur mobile, cela remplace la règle du bureau « jamais la liste des profils dans le menu ».
  • Vouvoiement dans tous les textes de l'app, comme partout ailleurs ; la pastille de portée se pose sous le libellé de CHAQUE réglage, jamais dans un en-tête de section.
  • Nouvelle version : pas d'entrée de la cloche (le serveur n'en écrit pas) ; proposée ici comme bandeau de l'app + écran « Les nouveautés » sur le modèle du bureau. Non codé cette nuit : à confirmer.
  • Maquettes en HTML seul, sans image externe : avatars et affiches sont des aplats dessinés, la page s'ouvre hors ligne.
