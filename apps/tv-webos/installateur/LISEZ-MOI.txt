Tentacle TV — installation sur un téléviseur LG
===============================================

Il faut Node.js sur l'ordinateur (https://nodejs.org, version « LTS »). C'est
le seul prérequis : le reste s'installe tout seul.


1. UN COMPTE DÉVELOPPEUR LG
---------------------------

  Gratuit, trois minutes, une seule fois :

      https://webostv.developer.lge.com

  « Sign In » en haut à droite, puis « CREATE ACCOUNT ». Choisissez votre
  pays, acceptez les conditions, entrez une adresse e-mail et un mot de
  passe, puis validez le lien de confirmation reçu par e-mail.


2. SUR LE TÉLÉVISEUR
--------------------

  a. Ouvrez le LG Content Store et installez « Developer Mode ».
  b. Lancez-la et connectez-vous avec le compte créé à l'étape 1.
  c. Mettez « Dev Mode Status » sur ON. Le téléviseur redémarre.
  d. Rouvrez « Developer Mode » et activez « KEY SERVER ».
  e. LAISSEZ CET ÉCRAN AFFICHÉ.

  L'étape (d) n'est pas facultative. « Dev Mode Status » sur ON ne suffit
  pas : c'est le Key Server, et lui seul, qui fait publier au téléviseur la
  clé sans laquelle aucune installation n'est possible. C'est aussi lui qui
  fait apparaître la phrase secrète.

  L'écran montre alors les deux choses que le script va demander :
    • l'adresse IP du téléviseur ;
    • la phrase secrète, 6 caractères, en bas à gauche.

  Le champ « Remain Session » indique le temps restant — 50 heures. Le
  bouton « EXTEND » le prolonge tant que la session n'a pas expiré.


3. SUR L'ORDINATEUR
-------------------

  WINDOWS
    Double-cliquez sur « Installer-Tentacle-TV.cmd ».

  MACOS
    Ouvrez Terminal (Applications › Utilitaires), tapez « bash » suivi d'un
    ESPACE, puis faites glisser « installer.sh » dans la fenêtre. Appuyez sur
    Entrée.

    Ne double-cliquez pas sur le fichier .command : macOS le bloque, voir plus
    bas.

  LINUX
    Ouvrez un terminal dans ce dossier et lancez ./installer.sh

  Répondez aux deux questions. Le script fait le reste : il télécharge la
  dernière version depuis GitHub, l'installe, et l'ouvre sur le téléviseur.


POURQUOI MACOS REFUSE LE DOUBLE-CLIC
------------------------------------

  Si vous voyez « ... n'a pas pu être ouvert » avec les seuls boutons
  « Placer dans la corbeille » et « Annuler », rien n'est cassé : macOS refuse
  d'ouvrir depuis le Finder tout fichier téléchargé qui n'a pas été signé par
  un développeur payant le programme Apple. Le clic droit › Ouvrir ne contourne
  plus ce blocage depuis macOS 15.

  Ce refus ne concerne QUE le Finder. Lancé depuis Terminal comme indiqué
  ci-dessus, le même fichier s'exécute normalement — c'est bash qui travaille,
  et bash, lui, est signé par Apple.

  Si vous tenez au double-clic, débloquez le fichier une fois pour toutes :

      Réglages Système › Confidentialité et sécurité › descendre jusqu'à
      « Sécurité » › « Ouvrir quand même »

  Le bouton n'apparaît que dans l'heure qui suit une tentative d'ouverture.


TOUT FAIRE EN UNE SEULE COMMANDE
--------------------------------

  Sur macOS et Linux, cette ligne collée dans un terminal télécharge la
  dernière version et la lance, sans rien laisser traîner sur le disque :

  cd "$(mktemp -d)" && curl -fsSL -O https://github.com/Knaox/Tentacle-TV/releases/download/webos-latest/installateur-tentacle-tv.zip && unzip -q installateur-tentacle-tv.zip && node "Tentacle TV - LG webOS/installer.mjs"


ENSUITE
-------

  Les mises à jour se font toutes seules : l'interface est servie par votre
  serveur Tentacle, ce paquet n'en est que la coquille. Vous n'avez à relancer
  ce script que si l'application disparaît du téléviseur — le mode développeur
  de LG désinstalle ce qu'il a installé quand la session expire (50 heures),
  sauf si vous la prolongez depuis l'application « Developer Mode ».
