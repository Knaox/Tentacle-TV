# Scénarios de référence — le socle transverse (T2)

Ce que tout écran partage, enregistré sur la référence `84f3cedd0` :

| Fichier | Ce qu'il garde |
|---|---|
| `accueil-rail.json` | Les trois exemples du format : focus d'entrée de l'accueil, contenu ↔ rail, Rail → Films → Retour |
| `demarrage.json` | Les entrées : sans session (jumelage), serveur injoignable (voile hors ligne, « Réessayer »), fiche ouverte par la navigation |
| `rail.json` | L'ordre du rail et ses bords, les allers-retours contenu ↔ rail depuis l'accueil, une rangée et une bibliothèque |
| `retour.json` | Retour depuis chaque écran principal (accueil, Pour vous, Ma liste, Favoris, bibliothèques, recherche, réglages, fiche, lecteur), jusqu'à la sortie de l'app |
