# @tentacle-tv/brand-intro-native

La VUE de l'ouverture du démarrage, partagée par l'app TV (Apple TV, Android TV)
et le mobile (iPhone, iPad, Android) : calques du logo, écran qui montre l'app,
horloge Reanimated sur le fil d'interface, porte du premier écran, adaptateur du
son natif `TentacleBootSound`. Le pur (courbes, géométrie, caméra, quand jouer)
est dans `@tentacle-tv/shared/brandIntro` ; chaque app branche ses primitives
(dégradé linéaire, découpe arrondie) et ses constantes générées du logo.

Carnet : `docs/OUVERTURE.md`.
